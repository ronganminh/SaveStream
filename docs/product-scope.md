# SaveStream V1 product scope

SaveStream monitors TikTok channels in the cloud and automatically records livestreams when they begin. The user does not need to keep a computer or browser open.

## Core journey

1. Create an account and complete onboarding.
2. Add a TikTok username or profile/live URL.
3. SaveStream monitors the channel continuously.
4. When the channel goes live, a cloud worker begins recording.
5. When the livestream ends, SaveStream stops and processes the file.
6. The completed recording becomes available for playback and download.

## V1 modules

- Authentication and account settings
- TikTok channel management
- Automatic monitoring and live detection
- Cloud recording lifecycle
- Recording library, playback and download
- Quota and subscription UI
- Notifications
- Admin system, worker, job and error views

## Out of scope for V1

- Douyin recording
- AI summaries and automatic clips
- Public recording marketplace
- Advanced video editing
- Team workspaces
- Chat replay and social publishing

The Add Channel flow is intentionally simple: enter a TikTok account or URL, resolve the creator, and start monitoring. There is no blocking permission-confirmation checkbox in the product flow.
