Huỷ
L13 là dialog theo ngữ cảnh. Có Cloud + bản tải xuống trên máy này → 3 lựa chọn.

Xoá Cloud nhưng giữ bản tải xuống → item chuyển thành LOCAL · Downloaded copy.
