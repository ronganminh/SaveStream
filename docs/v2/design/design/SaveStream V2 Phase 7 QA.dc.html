01Mọi màn có Light + DarkKhông → Đã sửaPhase 5/6 section nhiều state chỉ hiện Light. Thêm tweak statesTheme (light/dark) cho 2 file.
02ID màn không trùng giữa các phaseKhông → Đã sửaN04 (Phase 6, quyền tắt) trùng N04a–d (Phase 2). Đổi thành N05; mẫu push đổi thành N04e.

04Không mâu thuẫn quyết định giữa các phaseKhông → Đã sửaN03 nói "không xin quyền ở onboarding" trái với A09. N01 badge số trái với SsAppBar (chấm đỏ). Đã sửa note + decision.
05Có bản EN cho màn chínhKhông → Đã sửaThêm VI/EN cho Home, Watch List, Active Recording, Paywall, Settings, Empty, Error (trang này).
06Kiểm tra 360×800 và 430×932Không → Đã sửaPhase 1 có QA size cho H01/W01/L01. Bổ sung 7 màn trên ở cả 2 size, VI + EN.
07Local / Cloud luôn có icon + chữCóSsLocationChip, pill, banner Cloud Pack.
08Hit target ≥ 44 pxCóIcon button 44, list row 52, CTA 48–52.
09Text ≥ 12 px, contrast ≥ 4.5:1CóText cảnh báo dùng warnFg (#8A5D00) thay warn.
10Không quảng cáo trước aha moment, trên paywall, màn mua hàng, Player, ProCóBanner ad chỉ ở Home / Watch List / Bản ghi của Free.
11Paywall: 5 context, value prop giống nhau, chỉ đổi headline + copy phụCóM04.
12Giá + % tiết kiệm tính runtime từ storefrontCóM03 / M10 notes.
13User huỷ ≠ thất bại ≠ đang chờCóM07 / M08.
14Restore 4 trạng tháiCóM09.
15Cloud Pack ghi rõ không phải ProCóM10.
16Pro mua trên web không phải mua lạiCóM13.
17Huỷ / đổi gói mở trang subscriptions nativeCóM11, M12.
18Xoá: nút ghi rõ thứ bị xoá, theo ngữ cảnhCóL13-local / cloud / both, S03.
19Đăng xuất khi đang record không mất fileCóS16.
20Xoá tài khoản 2 bước + cảnh báo subscriptionCóS17 / S18.
21Session hết hạn khi record Local không mất dữ liệuCóG05.
22Không countdown giả, không bịa timestampCóDùng thời gian server, quy đổi giờ local.
23Ma trận Empty / Loading / Error / Offline / LimitCóPhase 6 #matrix.
24Mỗi màn có annotation platform / plan / nguồn stateCóTag SHARED / ANDROID / iOS · FREE / PRO · BACKEND / OS / STORE, gom trong Handoff.
